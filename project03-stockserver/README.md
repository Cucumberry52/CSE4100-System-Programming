# Project 03 · Concurrent Stock Server

[← 과제 목록](../README.md)

여러 클라이언트의 주식 조회·매수·매도 요청을 처리하는 서버를 두 방식으로 구현했습니다.

| 구현 | 연결 처리 | 공유 데이터 처리 |
| --- | --- | --- |
| `task_1` | `select` 기반 I/O 다중화 | 이벤트 루프에서 요청 처리 |
| `task_2` | 제한된 연결 버퍼와 미리 생성한 스레드 풀 | 세마포어를 사용한 재고 조회·갱신 동기화 |

주식 정보를 트리로 관리하고, `show`·`buy`·`sell`·`exit` 요청을 처리합니다. 서버 종료 시 파일에 재고 정보를 저장하는 로직을 포함합니다.

## 실행

스레드 풀 버전 기준:

```bash
cd task_2
make
./stockserver 50000
```

다른 터미널에서 같은 폴더로 이동해 클라이언트를 실행합니다.

```bash
./stockclient localhost 50000
```

클라이언트 입력 예시:

```text
show
buy 1 1
sell 1 1
exit
```

주식 ID와 수량은 `stock.txt`의 실제 데이터에 맞춰 사용합니다. `task_1`도 같은 방식으로 빌드하며, 두 서버를 동시에 실행하려면 다른 포트를 사용합니다.

## 다중 클라이언트

```bash
./multiclient localhost 50000 10
```

인자는 서버 주소, 포트, 클라이언트 수입니다.
