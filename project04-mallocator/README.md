# Project 04 · Mallocator

[← 과제 목록](../README.md)

C 프로그램을 위한 동적 메모리 할당기입니다. 제출한 `mm.c`에서 `mm_init`, `mm_malloc`, `mm_free`, `mm_realloc`을 구현했습니다.

## 구현 내용

- **분리 가용 리스트:** 블록 크기에 따라 20개 리스트로 나누어 빈 공간 관리
- **블록 탐색:** 크기 구간별 리스트에서 요청을 만족하는 블록 탐색
- **분할·병합:** 할당 시 남는 블록을 분할하고, 해제 시 인접한 빈 블록 병합
- **재할당:** 인접 블록 활용, 힙 확장 또는 새 블록 할당·복사를 통한 크기 변경

## 빌드

```bash
make
```

기본 Makefile에 `-m32`가 있으므로 GCC의 32비트 컴파일 환경과 라이브러리가 필요합니다. Ubuntu에서는 `gcc-multilib` 패키지가 설치된 환경을 사용할 수 있습니다.

## 실행

짧은 입력으로 확인:

```bash
./mdriver -V -f short1-bal.rep
./mdriver -V -f short2-bal.rep
```

제공된 전체 Trace 입력으로 확인:

```bash
./mdriver -V -t ./tracefiles/
```

`mdriver`는 할당·재할당·해제 요청을 재생해 정확성과 메모리 사용률·처리량 등을 평가하는 수업 제공 드라이버입니다.

제출본의 `mm.c`와 수업 제공 드라이버·지원 파일·Trace 입력을 함께 정리했습니다. 각 제공 파일의 원래 저작권 표기를 유지했습니다.
